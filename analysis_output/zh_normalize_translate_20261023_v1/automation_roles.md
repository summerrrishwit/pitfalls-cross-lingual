# 定时任务分工

生效：2026-10-24。替代原先单个综合定时任务；两个任务均每30分钟运行。

- `automation`：Qwen 运行检查与故障恢复。只负责生产健康、按现有运维配置诊断修复、恢复及生产完成汇总，不分派翻译审核、不导出审核接受集。Qwen后台持续执行，不由定时器逐批启动。
- `automation-2`：审核队列处理。只消费Qwen已经冻结的就绪英中包，分派真实Luna审核与Sol疑难裁决，保存分派/输出/归档；不控制Qwen进程。审核接受集和最终完整来源汇总仅由本任务导出。

审核为空时待命；审核追平不能停止Qwen或删除审核定时任务。Qwen全量生成与规定补试完成后，生产任务可以结束自身；全部已生成数据完成审核归档后，审核任务保存完整7250分母汇总并结束自身。保留失败、拒绝及待补证结果，终态Sol defer不反复重派。

执行细节仍以当前protocol、operations_policy、operations_tools、active_worker_runtime及逐包instructions为准；本次只拆分调度职责，没有改变冻结来源、生成/翻译提示词、输出、审核准则或故障恢复授权范围。认证/权限等非自动恢复项按当前配置诊断并报告，不因拆分而自动绕过。仅中文候选建设，不启动正式实验。
