# 下一轮问题卡：先检验修复方式，再决定扩量

状态：建议方案，尚未启动新实验；旧 v3/v4 结论和停止状态不变。

## 问题与工作假设

现有失败究竟来自可迁移修复方向缺失、干预位置/持续时间/幅度不合适，还是来源样本不足？当前证据不能区分这三者。优先假设是干预的选择性不足；这是假设，不是已证明的机制。

## 当前证据与边界

- 96 Development facts 中有 17 个实际生成定向缺陷，14 个保留 facts；严格双语特异病例仅 5 个。960 输入、4,256 干预调用不能代替独立事实数量。
- 8 候选都触发保留伤害，但仅覆盖两类方向及有限层/强度，不能推出 Qwen3-8B 无法修复。
- 实际 task estimator 为 EN/ZH ICL 原始激活均值；difference 为翻译均值减双语召回均值，尚未验证它们隔离了抗干扰因素。
- hook 在最后 prompt token 和后续每个生成 token 注入。no-op 等价性通过，不等于非零向量的强度和时间范围合适。
- 当前保留门槛是经验门槛。14 个独立同分布样本即便零损伤，二项模型单侧 95% 上界仍约 19.3%；约 59 个零损伤样本才使该上界低于 5%。选择偏差和分布迁移不被这个计算解决。
- Validation/Sealed 各 32，均未开启；不用于诊断、参数选择、重抽分割或补充来源。

## 最小下一步与决策

1. **局部可恢复性诊断**：在现有 Development 阳性上，将同事实 Neutral 的最后 prompt-token 激活局部替换到 Targeted；只在 prompt prefill 注入，随后正常解码。先固定少量层位，再看完整答案生成及完整序列 margin。增加自身替换、反向替换及匹配对照。它使用同事实的反事实参考，只能作诊断上界，不能报为可泛化修复；单点替换失败也不能否定所有其他组件/位置。
2. **可迁移修复**：只有诊断出现可恢复信号，才在四折训练来源内构造成对的抗干扰方向（同语言、同事实、尽可能匹配格式的 Neutral−Targeted 对照），以训练折正确/错误与保留行为约束方向；应用时不可读取评估事实的参考激活或正确答案。先限制到最后 prompt token、一个层位，强度按训练来源的激活范数校准。最终实用规则须同时覆盖 Original/Neutral/Targeted，不能只靠实验 arm 标签触发。
3. **最小对照**：保留原方法、no-op、反方向及五个范数匹配随机方向；仍以实际生成和保留门槛作主要选择，不用 margin 单独选优。完整语义裁决所有可能影响是否合格的样本，不能通过删除受损 facts 或改变评分准则让候选通过。
4. **来源数量诊断**：固定同一新方法，在每折可用 72 个来源 facts 内比较 18/36/72 的关系分层嵌套子集，预先固定少量种子。查看修复和保留是否随来源数量稳定改善。该步骤是学习曲线诊断，不是独立确认。方向与幅度校准不得使用被评估折的标签/激活；超参数如需选择，放在来源折内部。

判据：局部诊断有信号而来源独立方向无效，优先改方向估计/迁移方式；加入逐 token 注入才出现伤害，优先改时机；固定方法的来源学习曲线持续改善，才有支持扩充来源事实的直接证据。相关诊断需分别运行才能作对应判断。

## 什么时候扩量

- 现有 160 足以支持上述小规模诊断，不必先再生成大量同类 prompts。
- 有方法信号后，优先收集新的独立阳性事实及保留事实，覆盖原四类关系；来源扩充与评估扩充分开。
- 保留面板可预先设约 60–100 个独立 facts 的预算；约 60 只对应理想条件下零损伤的 5% 单侧上界，发生损伤或按关系分层后需重新计算。
- 确认样本量按最小关心的配对改善幅度、退化事件和预期阳性率规划；不直接指定“总量加到某数就足够”。同事实的翻译、改写和多个 distractor 仍属同一事实单位。
- 新增数据须预先定义采样、去重/泄漏组件、划分及用途；不能为了稀释已有失败临时扩大旧分母。旧 32/32 留出集继续保留，若确认能力不足则在打开前单独固定新增确认集协议。

## 方法来源

- [Activation patching 的方法与指标敏感性](https://arxiv.org/abs/2309.16042)：支持采用干预对照和多终点核验；不证明本项目的具体故障原因。
- [Contrastive Activation Addition](https://aclanthology.org/2024.acl-long.828/)：支持成对差分方向作为候选方法；其 Llama-2 结果不保证本项目 Qwen3-8B 有效。

如果目标仅是工程上降低错误，可另设无答案泄漏的提示约束或“完整上下文回答—仅问题回答”交叉检查基线。这些能否改善也需要测量；不能替代机制归因，不能把实验标签或正确答案用于触发。
