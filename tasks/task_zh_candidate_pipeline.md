# 当前方案：英文关系规范化 → 中文翻译 → 独立翻译审核

生效：2026-10-23。当前数据候选建设仅采用本方案。
当前运行：analysis_output/zh_normalize_translate_20261023_v1。

## 分工与全量执行

1. 固定原始来源问答及旧模型抽取结果；先盘点关系/类型签名，再使用版本化方向、定义目录。
2. Qwen3.8-max读取原始问答、已有三元组和旧模型标注，保留/修正主语、关系和英文事实输入。既有答案默认锁定；冲突、缺证据则defer，不擅自补事实。已知关系绑定目录；未列明的可提出精确新关系及定义，后续汇总同名冲突。
3. 关系规范化只做程序约束检查，不派Luna或Sol逐条复审。候选不称独立事实核验通过。
4. Qwen把规范化后的英文主语、输入、事实陈述、答案和别名翻译成中文。暂不生成其他五语，也不补造Neutral/Targeted/foil。
5. Luna子agent对照英文逐条审核中文等价、自然度、答案泄漏和身份对应；每个批次有实际agent ID、requested model和文件哈希。这里替代原GPT-5.5翻译审核工作。
6. 只有翻译不确定项交另一个Sol子agent裁决；明确的错误译文保留为reject，不能迭代筛到通过。当前首版自动内容修复次数为0；若采用修复，应另建有上限版本并独立审核。

Qwen是持久8并发、每请求2条；每批分别做规范化及翻译两次请求，合计同时在途最多8请求。不是规范化8+翻译8造成16个隐藏并发。
支持pipeline与bulk两种冻结模式：当前pipeline每20条已完成EN/ZH记录冻结审核包，Luna审核时Qwen继续处理全量。若希望等Qwen全量后再审核，可先不分派已就绪包；生产无需重跑。切勿按审核进度阻塞生成。
原请求过短的128输出token预检耗尽了思考预算，非认证失败；生产输出上限8192，认证/权限/身份等故障仍立即停。

## 正式实验关卡

“本运行文件已锁定”与“正式实验数据已冻结”不同。冻结须有实际成员清单和文件哈希，不能仅写true。

| 关卡 | 当前处理 | 正式进入实验前的完成条件 |
|---|---|---|
| 来源 | 原始7250输入已哈希锁定 | 原始成员可追溯，失败/排除不静默删掉，跨池重复事实统一ID |
| 关系定义 | 20个种子关系方向/定义锁定；Qwen可提新叶 | 全量后汇总关系，解决同ID不同定义/方向，锁定正式目录和逐事实成员；PNT再核对关系样本量与donor可行性，无额外逐条模型审核 |
| 正确答案与别名 | 继承候选别名+明确主答案，英文中文对应入包 | 锁定规范答案和各语评分alias集合，处理与错误选项/上下文重叠及冲突；改变alias后失效旧输入/评分绑定 |
| 翻译 | Luna逐条EN/ZH审核，Sol仅疑难 | 接受版本与英文完全绑定；英文语义或alias变更须重新翻译审核，不能沿用旧通过标签 |
| 最终实验输入 | 本轮仅核心事实字段 | 后续构建所需Original/Natural、Neutral、Targeted及可选MCQ；审核最终呈现文本的含义、泄漏、攻击/中性合同并锁定SHA。基础译文通过不能替代该审核 |
| 曝光 | 新请求逐次记录阶段、来源ID、模型、提示SHA及token；旧账本保留 | 补齐历史生成/筛选/目标行为曝光归属；未知项不能称clean holdout；不因删除旧输出而消除曝光 |
| split与泄漏组件 | 保留旧split/component为历史字段，缺失不随机编造 | 以规范事实、别名及语义关联组统一跨池重复，分配并锁定组件级split；全部语言/变体跟随同事实，不用Validation/Sealed结果调策略 |
| 目标模型与评分 | 本任务不执行 | 确定目标身份、生成参数、答案评分合同、修复上限、Development策略及Validation/Sealed使用边界 |
| 正式PNT | 不自动晋级 | 在上述冻结后另满足exact-HF/tokenizer/关系donor及机制合同；翻译通过不等于PNT样本 |

运行 formal_entry_gates.json 中未完成项必须保持false。本任务完成中文候选建设后输出缺口清单，不把“安排了关卡”写成“所有关卡已完成”。

## 产物与旧数据清理

manifest.json/input.jsonl/relation_catalog.json/runtime是本次不可变绑定。batches保存新规范化及译文，review_packets保存独立译文审核，exposure.jsonl保存本次曝光，status.json保存统计。已废止的关系逐条复审方案、专用实现/配置/测试及派生数据已于2026-10-24删除。原归档位置仅保留删除凭据、逐文件哈希清单与历史模型接触元数据，不再保留可恢复的旧方案或结果。原始抽取账本、原中文/五语译文和原160实验保留；历史曝光没有清零。
